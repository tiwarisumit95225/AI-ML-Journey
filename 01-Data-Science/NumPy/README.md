# NumPy

NumPy (Numerical Python) is the fundamental library for numerical computing in Python. It provides support for multidimensional arrays, mathematical operations, and data manipulation, making it an essential tool for Data Science, Machine Learning, and Artificial Intelligence.

## Learning Objectives

* Understand NumPy arrays
* Learn indexing and slicing
* Perform mathematical operations on arrays
* Work with array reshaping and broadcasting
* Apply statistical functions
